Black Marble Pavilion — Marble Series
Extract the entire archive. From this directory run:
  python3 -m http.server 8000
Open http://localhost:8000 in a WebGL 2 browser. Scroll down to tour the pavilion, pull back through the illuminated gate and reveal the marble BIPV panel. Scroll up to reverse the sequence.
All models, textures, and JavaScript dependencies are included locally.
The new scroll timing and gate registration are in reveal.js. The camera and cloud continuation are in camera.js and scene.js.
